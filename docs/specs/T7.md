# T7 — UI: «Ящики», «История», «Статистика»

Контекст: `docs/plan-parallel-and-dashboard.md`, раздел 3. Опирается на T5 (эндпоинты)
и на каркас T6: `app.js` с `registerPage(name, {title, render})` и `ctx`
(`api`, `onLive`, `link`, форматтеры), стили в `style.css` (CSS-переменные).

**Меняются только три файла страниц**, которые T6 создал заглушками. `app.js`,
`index.html`, `style.css` не трогать. Нужен стиль — инлайн через CSS-переменные
каркаса или `<style>`, вставляемый страницей один раз (с префиксом классов `t7-`).

## «Ящики» (`pages/mailboxes.js`)

Данные: `/v1/mailboxes`. Таблица (на узком экране — карточки): ящик, задач, в работе,
ждут ревью, принято, сбои, последняя активность (относительное время). Клик по ящику →
`#/history?mailbox=<имя>`. Обновление по живым событиям, не чаще раза в 2 с.

## «История» (`pages/history.js`)

Данные: `/v1/threads` с фильтрами из query части хэша (`#/history?mailbox=&repo=&state=&q=`).

- Панель фильтров: ящик (список из `/v1/mailboxes`), репозиторий (уникальные из
  загруженных), состояние (`active|review|done|failed|все`), поиск по тексту (debounce
  300 мс). Фильтры отражаются в хэше — ссылку можно сохранить.
- Таблица: тикет, заголовок, репо (basename), ящик, попыток, последний kind/state
  (бейдж), модель, обновлён. Строка — ссылка на `#/thread/<id>`.
- Пагинация «показать ещё» (`offset`, по 50).

## «Статистика» (`pages/stats.js`)

Данные: `/v1/stats?group=mailbox|repo|model` — переключатель группировки (в хэше).

- Таблица по группам: тикетов, результатов, принято с первого ревью (число и %),
  вердиктов rework, таймаутов, сбоев, медиана ожидания в очереди, медиана исполнения,
  токены in/out.
- Над таблицей — по каждой метрике-доле горизонтальная полоска на строку (простые
  `div` с шириной в %, без библиотек): «принято с первого ревью, %» и «медиана
  исполнения».
- `null` показывать как «—». Подсказка (`title`) с определением каждой метрики (взять из
  `docs/specs/T5.md`, раздел 2, `stats`).
